「见山Terrascope」演示页部署指南（三条免费路径，任选其一）
====================================================

本包为自包含静态站点：index.html + vendor/（图表库/样式/背景图全部本地化，零外链）。
部署后评委在任意网络环境均可打开；手机、平板、电脑自适应。

----------------------------------------------------
方式一：Netlify Drop（最快，约 2 分钟，无需命令行）
1. 解压本 zip
2. 打开 https://app.netlify.com/drop （首次需免费注册/邮箱登录）
3. 把整个「见山Terrascope_演示部署包」文件夹拖进页面 → 立即得到 https://xxxx.netlify.app 演示链接

----------------------------------------------------
方式二：GitHub Pages（适合校内展示+代码留存）
1. 解压本 zip，登录 github.com 新建仓库（如 yunqi-naxi-demo，公开）
2. 上传 index.html 和 vendor/ 文件夹（网页端 Add file → Upload files 即可）
3. 仓库 Settings → Pages → Branch 选 main / 保存 → 约 1 分钟后得到
   https://你的用户名.github.io/yunqi-naxi-demo/

----------------------------------------------------
方式三：Vercel
1. 解压本 zip，登录 https://vercel.com/new
2. 导入刚建的 GitHub 仓库（或用 vercel CLI 直接上传文件夹）
3. 默认静态部署，得到 https://xxxx.vercel.app

----------------------------------------------------
注意事项
- 页面内"民宿底座 API"在静态托管下不可达，会自动降级为内置演示卡（已做容错，不影响演示）。
- P1 接入 p0-server 后，将 vendor 与 index.html 一同放入服务器静态目录即可，无需改代码。
- 如需自定义域名（如 yunqi.example.com），三个平台免费版均支持绑定。
- 报名/答辩材料中引用演示链接时，建议同时附一句"全部数据可溯源、演示版标注数据来源"口径。
